# Session Builder

A weekly workout planner for a mix of gym sessions and studio classes. It helps plan each week, balance training across body parts, and build a session for a given day.

## Features

- Weekly plan with a session for each day, plus an optional second session.
- Session builder with body-part selection, time-at-the-gym options, and an option that lowers leg volume when studio classes already train the legs.
- Weekly load view by body part, with a short summary of what gets the most and least work.
- Tick-off tracking and a calendar history view.
- Backup export and import as a JSON file.

## Built with

- Claude (artifact page)
- HTML, CSS, and vanilla JavaScript
- Browser localStorage for saving data on the device

## Notes

- Data stays on the device where it's used. Export a backup to move it.
- This is a personal planner, not medical or fitness advice.
- Not affiliated with any studio or brand named in the app.
